# PanelResizeHandle

Poignée visuelle et accessible commune aux panneaux redimensionnables du studio.

- `orientation` adapte la pilule et le curseur.
- `active` affiche l’état de glissement.
- Les valeurs et la cible ARIA sont fournies par le panneau consommateur.
- Le calcul de taille, la capture du pointeur et les raccourcis restent sous la responsabilité du panneau.
